    남도현 | Software & AI Engineer

    문제의 본질과 근본 원인을 파고들어, 확장 가능하고 신뢰할 수 있는 AI 시스템으로 해결합니다.

    Computer Vision 모델 개발부터 LLM 기반 Agentic AI와 AI 백엔드 시스템까지 경험한 소프트웨어·AI 엔지니어입니다. 데이터의 특성과 시스템의 병목을 분석하고, 문제를 적절한 구조로 다시 정의하여 실제 서비스로 연결하는 일을 좋아합니다.

    Core Strengths

    Root-Cause Problem Solving

    표면적인 파라미터 튜닝이나 임시방편에 머무르지 않고, 시스템 로그와 데이터 특성을 분석해 문제의 원인을 찾습니다. 필요하다면 문제를 탐지와 분류, 모델과 서비스처럼 더 적절한 구조로 재정의합니다.

    Production-Minded Architecture

    모델의 정확도뿐 아니라 응답 지연, 비동기 처리, 데이터 영속성, 결합도와 운영 안정성까지 고려하여 실험 결과를 실제 서비스로 연결합니다.

    Fast Adaptation & Data-Driven Decisions

    Rust, LangGraph 1.x, uv와 같은 새로운 기술을 공식 문서와 소스코드로 빠르게 습득하고, 추측 대신 벤치마크와 정량적인 성능 지표를 바탕으로 의사결정을 내립니다.
